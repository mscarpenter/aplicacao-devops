# Aplicação DevOps - Node.js & Express

Esta é uma aplicação web desenvolvida em Node.js com o framework Express.js como parte da Avaliação 1 da disciplina de Ferramentas de Implantação Contínua (DevOps).

## Tecnologias Utilizadas

- **Node.js** - Ambiente de execução JavaScript
- **Express.js** - Framework para desenvolvimento de servidores HTTP
- **Git & GitHub** - Controle de versão e colaboração em equipe

---

## Endpoints da Aplicação

- **`GET /`** - Serve a página de boas-vindas HTML (`views/index.html`).
- **`GET /integrantes`** - Retorna uma estrutura JSON contendo a lista dos nomes dos integrantes do grupo.

Siga as instruções abaixo para clonar e executar a aplicação em sua máquina local:

### 1. Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em seu sistema.

### 2. Clonar o repositório
```bash
git clone [https://github.com/mscarpenter/aplicacao-devops.git](https://github.com/mscarpenter/aplicacao-devops.git)
